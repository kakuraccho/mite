# Mite モック仕様インデックス

このディレクトリは、Miteの仕様探索用モックに関するプロダクト仕様を管理する。

## 読む順番

| ファイル | 内容 |
|---|---|
| `00-overview.md` | プロダクト、利用者、今回の目的、対象範囲 |
| `01-state-model.md` | 状態、イベント、データ、守るべき不変条件 |
| `02-support-flow.md` | 困りごと記録から家族支援、支援終了まで |
| `03-guide-creation-flow.md` | 支援内容から仮ガイドを作成・保存するまで |
| `04-guide-usage-flow.md` | ガイド一覧・自動照合からガイドを利用するまで |
| `05-screens-and-ui.md` | 祖父側、家族側、デモ画面のUI要件 |
| `06-mock-data-and-demo.md` | モックデータ、デモシナリオ、疑似同期 |
| `07-acceptance-criteria.md` | 完了条件、テスト観点 |
| `90-open-questions.md` | まだ決まっていないこと |
| `91-decisions.md` | モック実装のために置いた暫定判断 |

## 仕様の位置づけ

- 現時点では**正常系の検証**を優先する
- 異常系・復旧方法は、正常系を触った結果として見つけていく
- `90-open-questions.md` の内容は確定仕様ではない
- `91-decisions.md` の「暫定」は本番仕様ではなく、モックを通すための仮置きである
- 実装中に仕様が変わった場合は、コードだけでなく該当ファイルも更新する

## 仕様ID

- `SUP-*`：支援依頼・家族支援
- `GCR-*`：ガイド作成
- `GUS-*`：ガイド利用
- `UI-*`：画面・表示
- `DATA-*`：データ
- `AC-*`：受け入れ条件
