# 03. ガイド作成フロー

## 1. 対象

家族による支援で問題が解決したあと、支援中の疑似記録をもとに仮ガイドを作成し、家族と祖父が確認して保存する正常系を定義する。

## 2. 前提

- 支援セッションが `guideDecision` まで進んでいる
- 家族が `ガイドを作成する` を選ぶ
- 支援中の疑似スクリーンショット記録が1件以上ある
- 実AI、実画像解析は使用しない

## 3. 正常系

### GCR-01：仮ガイドを生成する

1. 家族が `ガイドを作成する` を押す
2. 両側に「ガイドを準備しています」と表示する
3. Miteは固定テンプレートから仮ガイドを生成する
4. 一定の短い待ち時間後、レビュー画面へ移る

生成処理は必ず同じ入力から同じ結果を返す。

### GCR-02：仮ガイドの内容

仮ガイドには最低限、次を含める。

- タイトル
- 代表画像
- 1つ以上の手順
- 各手順の疑似スクリーンショット
- 各手順の短い説明文
- 現在のページ番号

デモ用の初期タイトル：

> 認証コードを確認したあと、元の画面へ戻る

デモ用の初期手順：

1. 画面下のタスクバーを見ます。
2. 飛行機の購入画面のアイコンを押します。
3. 元の画面に戻ったら、控えた番号を入力します。

### GCR-03：家族側でレビュー・編集する

1. 家族側へ編集可能な仮ガイドを表示する
2. 家族は現在の手順を前後へ移動できる
3. 家族は最低限、次を編集できる
   - ガイドタイトル
   - 各手順の説明文
4. 編集内容は祖父側プレビューへ即時反映する
5. 家族は `保存する` を押せる

画像の差し替え、手順の追加・削除・並び替えは、今回の必須範囲に含めない。必要性が出た場合は未決定事項として記録する。

### GCR-04：祖父側で確認する

1. 祖父側へ、家族が現在確認している手順と同じ手順を表示する
2. 祖父側は読み取り専用とする
3. 祖父側ではタイトル、画像、説明、ページ番号を確認できる
4. 祖父側に「家族と一緒にガイドを確認しています」と表示する

祖父側からの編集・承認操作は、今回の必須範囲に含めない。

### GCR-05：保存して終了する

1. 家族が `保存する` を押す
2. ガイドを `published` としてモック保存する
3. 保存したガイドが祖父側のガイド一覧に表示されるようにする
4. 両側に保存完了を表示する
5. 支援接続を終了する
6. 祖父側と家族側を通常状態へ戻す

## 4. ガイドを作らない分岐

家族が `作成せず終了する` を選んだ場合は、仮ガイド生成へ進まず、支援接続だけを終了する。

## 5. 表示文言例

| 状態 | 表示例 |
|---|---|
| 生成中 | `今回の支援からガイドを準備しています。` |
| 家族レビュー | `内容を確認して、必要なところだけ直してください。` |
| 祖父レビュー | `家族と一緒に、次回使うガイドを確認しています。` |
| 保存完了 | `ガイドを保存しました。次から「ガイドを見る」で使えます。` |

## 6. 最低限の受け入れ条件

- 支援終了時にガイド作成を選べる
- 疑似生成中状態を経て、決定的な仮ガイドが表示される
- 家族がタイトルと説明文を編集できる
- 編集内容が祖父側の読み取り専用表示へ反映される
- 前後の手順を確認できる
- 保存後、ガイド一覧へ追加される
- 保存と同時に支援接続が終了する
