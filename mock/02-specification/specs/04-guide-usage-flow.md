# 04. ガイド利用フロー

## 1. 対象

祖父が保存済みガイドを選び、スクリーンショットと説明を1ステップずつ見ながら操作する正常系を定義する。

入口は次の2つである。

1. 左端パネルの `ガイドを見る`
2. 困りごと記録後の類似ガイド照合

## 2. 一覧から利用する正常系

### GUS-01：ガイド一覧を開く

1. 祖父が画面左端の約20pxの領域へマウスを乗せる
2. 展開したパネルから `ガイドを見る` を押す
3. 保存済みガイドの一覧を表示する
4. 各ガイドには最低限、次を表示する
   - タイトル
   - 代表画像
   - `このガイドを見る` ボタンまたは同等の選択領域

一覧は `published` のガイドだけを表示する。

### GUS-02：ガイドを選ぶ

1. 祖父は現在の困りごとに合うガイドを選ぶ
2. 選択したガイドの最初の手順を表示する
3. ガイド表示は、実際のPC画面を操作しながら見られる小さなパネルまたはウィンドウとして表現する

今回、実Windowsデスクトップの最前面表示は実装せず、ブラウザ内のダミーデスクトップ上で表現する。

### GUS-03：1ステップずつ操作する

ガイド表示には最低限、次を含める。

- ガイドタイトル
- `STEP n / N`
- 現在の手順のスクリーンショット
- 現在の手順の説明文
- `前へ`
- `次へ` または最終手順の `できました`
- `遠隔支援へ移る`

1. 祖父は説明と画像を見て、ダミー画面上で操作した体で進める
2. `次へ` を押すと次の手順へ進む
3. 2手順目以降では `前へ` で戻れる
4. 最終手順で `できました` を押すと完了画面を表示する
5. 完了後はガイドを閉じ、通常状態へ戻れる

操作の自動検知は行わない。祖父が自分でページ送りを行う。

## 3. 類似ガイドから利用する正常系

### GUS-04：類似ガイドが見つかった場合

1. 祖父が困りごとを記録する
2. Miteが疑似照合を行う
3. 類似ガイドが見つかった場合、「似たガイドが見つかりました」と表示する
4. 該当ガイドの最初の手順へ移る
5. `GuideRun.entry` は `similarGuideMatch` とする
6. 以降は `GUS-03` と同じ

実AI検索は行わず、デモ設定または固定ルールで該当ガイドを返す。

## 4. 遠隔支援へのフォールバック

### GUS-05：途中で分からなくなった場合

1. 祖父は任意の手順で `遠隔支援へ移る` を押せる
2. 確認画面を表示する
3. 祖父が続行すると、ガイド利用を `fallback` 状態にする
4. 支援依頼作成の流れへ移る
5. 以降は `02-support-flow.md` に従う

現在のガイド名や手順番号を支援依頼へどこまで引き継ぐかは未決定である。モックでは、後から変更しやすい形で暫定動作を置き、`90-open-questions.md` と `91-decisions.md` に記録する。

## 5. 表示文言例

| 状態 | 表示例 |
|---|---|
| 一覧 | `どの操作で困っていますか？` |
| 類似ガイド発見 | `似たガイドが見つかりました。まずはこちらを見てみましょう。` |
| ガイド利用中 | `この画面を見ながら、1つずつ操作してください。` |
| フォールバック | `このまま家族に相談しますか？` |
| 完了 | `できました。ガイドを終了します。` |

## 6. 最低限の受け入れ条件

- 左端パネルからガイド一覧を開ける
- 一覧からガイドを選べる
- 画像、説明、ページ番号を1ステップずつ表示できる
- 前後へ移動できる
- 最終手順を完了できる
- 困りごと記録時の類似ガイドから同じ利用画面へ入れる
- 任意の手順から遠隔支援へ移れる
