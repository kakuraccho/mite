# 00. プロダクト概要とモック範囲

## 1. プロダクト名

Mite（ミテ）

## 2. 解決したいこと

祖父は、PCのマウス操作や文字入力自体がまったくできないわけではない。一方で、見慣れない画面が出たときや、複数の画面を行き来するときに、次に何をどの順番で操作すればよいか分からなくなることがある。

Miteは、離れている家族が祖父の画面を見ながら操作場所を示し、祖父本人が操作して解決できるようにする。また、一度家族と解決した内容をガイドとして残し、次回は祖父が一人で試せるようにする。

## 3. 大切にする方針

- 本人ができる操作は本人が行う
- 助けを求めるための操作を増やしすぎない
- 家族による判断や支援を中心にする
- AIは家族を置き換えず、整理や反復作業を補助する
- 一度の支援を、その場だけで終わらせない

## 4. 利用者

### 祖父

- PC操作中に困りごとを記録する
- 保存済みガイドを見る
- 家族からの着信に応答する
- 家族のマーキングと説明を参考に自分で操作する
- 仮ガイドを家族と一緒に確認する
- ガイドを1ステップずつ利用する

### 家族

- 支援依頼の通知を見る
- 困ったときの画面とコメントを見る
- 祖父のオンライン状態を見る
- 対応できるタイミングで発信する
- 祖父の画面を見ながらマーキングして説明する
- 支援後にガイドを残すか判断する
- 仮ガイドを確認・編集・保存する

### Mite

- 困りごとの画面とコメントを記録する
- 類似ガイドの有無を確認する
- 支援依頼を家族へ知らせる
- 祖父と家族を接続する
- 画面共有、マーキング、通話中であることを表現する
- 支援中の記録をもとに仮ガイドを作る
- 保存済みガイドを祖父へ表示する

## 5. 今回検証する正常系

### Flow A：家族に支援してもらい、ガイドを作る

```text
祖父が困る
→ 左端パネルから困りごとを記録する
→ 疑似スクリーンショットと任意コメントを残す
→ 類似ガイドがない
→ 家族へ支援依頼が届く
→ 家族が依頼とオンライン状態を見る
→ 家族が祖父へ発信する
→ 祖父が応答する
→ 画面共有とマーキングで支援する
→ 解決する
→ 家族がガイドを作成することを選ぶ
→ 仮ガイドを家族と祖父が確認する
→ 家族が編集して保存する
→ 接続を終了する
```

### Flow B：困りごと記録時に類似ガイドを使う

```text
祖父が困る
→ 左端パネルから困りごとを記録する
→ 疑似スクリーンショットと任意コメントを残す
→ 類似ガイドが見つかる
→ 該当ガイドの利用へ移る
→ 1ステップずつ操作する
→ 完了する
```

### Flow C：一覧からガイドを使う

```text
祖父が以前にも同じような困りごとがあったことを思い出す
→ 左端パネルからガイドを見る
→ 一覧から現在の状況に合うガイドを選ぶ
→ スクリーンショットと説明を1ステップずつ見る
→ 前後のページへ移動しながら操作する
→ 完了する
```

### Flow D：ガイド利用中に家族支援へ移る

```text
ガイドを利用する
→ 途中で分からなくなる
→ 「遠隔支援へ移る」を押す
→ 支援依頼の流れへ移る
```

## 6. 今回のモックで確認したいこと

- 画面左端の約20pxの領域から目的の操作を開始できるか
- 「困りごとを記録する」と「ガイドを見る」の違いが分かるか
- 類似ガイドがある場合に、支援依頼より先にガイドへ移る流れが自然か
- 困った瞬間と家族が対応する瞬間が離れていても理解できるか
- 家族が祖父のオンライン状態を見て発信する流れが分かるか
- 家族側のクリックによるマーキングで操作場所を伝えられるか
- ガイドを作るかどうかの判断が支援終了時に自然か
- 家族によるガイド編集が負担になりすぎないか
- 祖父がガイドを1ステップずつ見ながら実際の画面を操作できそうか
- ガイドから遠隔支援への切り替えが見つけやすいか

## 7. 将来の展望として扱うもの

- 音声文字起こし
- 遠隔操作
- ガイドに沿って操作するときのAI支援
- 支援中のインカメラ映像
- ガイドのAI検索

これらはモックの主動線へ追加しない。
