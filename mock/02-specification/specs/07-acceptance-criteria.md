# 07. 受け入れ条件

## 1. 全体

### AC-001

リポジトリの起動方法が明確であり、開発環境でアプリを起動できる。

### AC-002

`/demo` から祖父側と家族側の正常系を、ページ再読み込みなしで確認できる。

### AC-003

実際の画面共有、マイク、カメラ、通知、外部APIの権限を要求しない。

### AC-004

モックデータだけを使用し、ネットワーク接続なしでも主要フローを確認できる。

## 2. 支援フロー

### AC-SUP-001

祖父が左端パネルから困りごと記録を開始できる。

### AC-SUP-002

疑似スクリーンショットと任意コメントを確認して送信できる。

### AC-SUP-003

類似ガイドなしの場合、家族側へ同じ支援依頼が表示される。

### AC-SUP-004

家族が祖父のオンライン状態を確認し、発信できる。

### AC-SUP-005

祖父が着信へ応答すると、両側が同じ支援中状態になる。

### AC-SUP-006

家族側の共有画面クリックが、祖父側の同じ相対位置へマーカーとして反映される。

### AC-SUP-007

支援中に5秒ごとの疑似記録イベントが増える。

### AC-SUP-008

解決後、ガイド作成または作成せず終了を選べる。

## 3. ガイド作成

### AC-GCR-001

ガイド作成を選ぶと、疑似生成中状態を経て仮ガイドが表示される。

### AC-GCR-002

家族がタイトルと各手順の説明文を編集できる。

### AC-GCR-003

家族側の編集が祖父側プレビューへ反映される。

### AC-GCR-004

祖父側は編集できず、家族と同じ現在手順を確認できる。

### AC-GCR-005

保存後、ガイドが公開済み一覧へ追加され、支援接続が終了する。

## 4. ガイド利用

### AC-GUS-001

祖父が左端パネルからガイド一覧を開ける。

### AC-GUS-002

祖父が一覧からガイドを選び、最初の手順を表示できる。

### AC-GUS-003

画像、説明、ページ番号、前後ボタンが表示される。

### AC-GUS-004

最終手順で完了できる。

### AC-GUS-005

類似ガイドありの場合、困りごと記録後に該当ガイド利用へ移れる。

### AC-GUS-006

ガイド途中から遠隔支援へ移り、支援依頼作成へ接続できる。

## 5. リセット・再現性

### AC-DEMO-001

リセットで選択シナリオの初期状態へ戻れる。

### AC-DEMO-002

Scenario A〜Dを順番を問わず再実行できる。

### AC-DEMO-003

現在状態と直近イベントが開発用領域で確認できる。

## 6. テスト

最低限、次に自動テストを付ける。

- 類似ガイドなしから支援依頼へ進む状態遷移
- 類似ガイドありからガイド利用へ進む状態遷移
- 着信応答から支援中へ進む状態遷移
- マーカー相対座標の算出と反映
- 支援終了からガイド作成・スキップへの分岐
- ガイド編集内容の共有
- ガイドの前後移動と最終完了
- ガイドから支援依頼へのフォールバック
- リセット

## 7. 検証コマンド

既存リポジトリのコマンドを優先する。一般的には次を実行する。

```bash
npm run lint
npm run test
npm run build
```

実行できなかったコマンドや失敗した項目は、完了報告で明記する。
