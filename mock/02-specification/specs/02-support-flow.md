# 02. 困りごと記録から家族支援まで

## 1. 対象

祖父が困りごとを記録し、類似ガイドが見つからなかった場合に、家族へ支援依頼を送り、家族が後から発信して支援する正常系を定義する。

## 2. 前提

- 祖父側と家族側のMiteが利用できる
- 家族は1人を想定する
- 実画面、実通知、実音声、実ネットワークは使用しない
- 祖父の画面はダミーの「メール画面」を使用する
- デモ設定で類似ガイドは「なし」にする
- 祖父のオンライン状態はデモ設定で「オンライン」にする

## 3. 正常系

### SUP-01：左端パネルを開く

1. 祖父側画面の左端に、約20pxの縦長領域を常時表示する
2. 祖父がその領域にマウスを乗せる
3. パネルが右方向へ一時的に展開する
4. パネルには少なくとも次を表示する
   - `困りごとを記録する`
   - `ガイドを見る`

モックでは、パネルが閉じた状態でも支援機能の入口であることが最低限分かる見た目にする。

### SUP-02：困りごとを記録する

1. 祖父が `困りごとを記録する` を押す
2. Miteが現在の画面を撮った体で、ダミー画像を表示する
3. 任意コメントの入力欄を表示する
4. 祖父はコメントを入力して送信するか、空欄のまま送信できる

サンプルコメント：

> 番号は分かったけれど、飛行機の画面に戻れません

### SUP-03：類似ガイドを確認する

1. 送信後、Miteは「似たガイドがないか確認しています」と表示する
2. モック照合を実行する
3. 類似ガイドがない場合、支援依頼を作成する
4. 祖父側へ、家族に知らせたことと、家族からの連絡を待つことを表示する

この処理で実際の画像解析やAI検索は行わない。

### SUP-04：家族へ支援依頼を表示する

1. 家族側に新しい支援依頼の通知を表示する
2. 家族が通知または依頼一覧から依頼を開く
3. 家族側に次を表示する
   - 記録時刻
   - 疑似スクリーンショット
   - コメント
   - 祖父のオンライン状態
   - `電話をかける` ボタン
4. 通知を見ただけでは自動発信しない

### SUP-05：家族から電話をかける

1. 家族が対応できるタイミングで `電話をかける` を押す
2. 家族側は「呼び出しています」状態になる
3. 祖父側に着信画面を表示する
4. 祖父が `電話に出る` を押す
5. 両側へ接続中であることを短時間表示する
6. 支援中画面へ移る

実際の音声は扱わず、「会話中」であることをUIで示す。

### SUP-06：画面を見ながら支援する

1. 家族側へ祖父のダミー画面を表示する
2. 祖父側にも同じダミー画面を表示する
3. 家族が共有画面内をクリックする
4. クリック位置を相対座標へ変換する
5. 祖父側の対応位置に、丸または同等の目立つマーカーを表示する
6. 家族側にも現在のマーカーを表示する
7. 新しい位置をクリックした場合、現在のマーカーを新しい位置へ移す
8. 祖父はマーカーと家族の説明を参考に、自分で操作した体で進める

今回、祖父による実PC操作やクリック検知は行わない。デモ用の「状況を再現した」「解決した」操作で次へ進めてよい。

### SUP-07：支援中の記録を表現する

1. 支援中は5秒ごとに疑似記録イベントを発生させる
2. 実画像は保存せず、記録件数と時刻をデモ表示する
3. 支援終了時に、この記録が仮ガイドの材料になることを表現する

### SUP-08：問題解決後の分岐

1. 家族側で `問題を解決した` を押す
2. 家族側に次を表示する
   - `今回の内容からガイドを作成しますか？`
   - `ガイドを作成する`
   - `作成せず終了する`
3. `作成せず終了する` を選んだ場合、接続を終了する
4. `ガイドを作成する` を選んだ場合、`03-guide-creation-flow.md` へ進む

## 4. 祖父側に常に伝えること

| 状態 | 表示例 |
|---|---|
| 依頼送信後 | `家族に知らせました。家族からの連絡をお待ちください。` |
| 着信 | `家族から連絡が来ています。` |
| 接続中 | `家族とつないでいます。` |
| 支援中 | `家族が今の画面を見ながら説明しています。` |
| 記録中 | `次回のガイド作成に使うため、支援内容を記録しています。` |
| 終了 | `支援を終了しました。` |

文言はプロトタイプ検証で変更してよいが、専門用語へ置き換えない。

## 5. 最低限の受け入れ条件

- 左端パネルから困りごと記録を開始できる
- コメントを空欄でも送信できる
- 類似ガイドなしの場合に家族側へ依頼が現れる
- 家族が依頼と祖父の状態を確認できる
- 家族から発信し、祖父が応答できる
- 両側が同じ支援中状態になる
- 家族側のクリック位置が祖父側へ反映される
- 5秒ごとの疑似記録が増える
- 解決後にガイド作成または終了を選べる
