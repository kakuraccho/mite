# Mite 仕様探索用モック

祖父側と家族側の支援フロー、ガイド作成、ガイド利用をブラウザ内で確認するReactモックです。実際の画面取得、通話、通知、AI、バックエンドは使用しません。

## 起動方法

```bash
npm install
npm run dev
```

起動後、`http://localhost:5173/demo` を開いてください。

## 画面

| ルート | 内容 |
|---|---|
| `/demo` | 祖父側・家族側・デモ操作を同時表示する主検証画面 |
| `/grandfather` | 祖父側だけを表示 |
| `/family` | 家族側だけを表示 |

個別ルートは、`/demo` から同じタブ内で移動した場合に同じメモリ上の状態を表示します。別タブ間の同期と再読み込み後の復元は今回のモックには含めていません。

## シナリオ

`/demo` 左側の開発用パネルでScenario A〜Dを選択します。シナリオを切り替えると、そのシナリオの決定的な初期データへ戻ります。

- Scenario A：困りごとを記録し、家族の支援後にガイドを作成・保存する
- Scenario B：困りごと記録後に見つかった類似ガイドを使う
- Scenario C：保存済みガイド一覧からガイドを使う
- Scenario D：ガイド途中から家族への支援依頼へ移る

左端の細い `Mite` 領域へマウスを乗せると、祖父側の開始メニューが開きます。支援中の疑似記録だけは仕様どおり5秒ごとに増えます。

## モックの範囲

- 疑似スクリーンショットはHTML/CSS製の固定画面です
- 類似ガイド照合はデモ設定の `あり / なし` だけで決まります
- 通話・画面共有・通知は画面上の状態だけで表現します
- ガイド生成は固定の3手順テンプレートです
- マイク、カメラ、画面共有、ブラウザ通知の権限を要求しません
- 外部APIやAPIキー、ネットワーク上のバックエンドを使用しません
